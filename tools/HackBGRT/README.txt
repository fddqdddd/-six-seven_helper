HackBGRT — замена логотипа при включении ПК (UEFI)
==================================================

1. Скачайте HackBGRT с GitHub:
   https://github.com/Metabolix/HackBGRT/releases
   (файл HackBGRT-x.x.x.zip)

2. Распакуйте содержимое zip СЮДА, чтобы рядом лежали:
   - setup.exe
   - bootx64.efi
   - config.txt (будет перезаписан Six_Seven)
   и остальные файлы из архива.

3. Положите PNG-кадры в assets/sprites/loading/ (относительно Six_Seven.exe).

4. В трее Six_Seven: «Установить логотип загрузки ПК» (нужны права администратора).

5. Перезагрузите компьютер.

Требования:
- Windows в режиме UEFI (не Legacy BIOS)
- На части ПК нужно отключить Secure Boot в настройках прошивки
- Логотип производителя может мелькнуть на долю секунды — это ограничение UEFI

Анимация: при нескольких PNG при каждой перезагрузке выбирается случайный кадр.
Полноценное видео на экране прошивки без модификации BIOS невозможно.

Удаление: трей → «Убрать логотип загрузки ПК» → перезагрузка.
