# Свои анимации для Six_Seven

Пошаговое руководство: как нарисовать кадры, положить их в проект и привязать к действию персонажа.

## 1. Куда класть файлы

Каждая анимация — **отдельная папка** внутри `assets/sprites/`:

```
assets/sprites/
  idle/           ← покой (дыхание: 0001.png, 0002.png, …)
  def/blink/      ← моргание при «скуке»
  click/wave/     ← помахать (ПКМ)
  leaving/sink/   ← выход приложения (300 кадров и т.д.)
  movingU/        ← ходьба вверх
```

Рядом с `Six_Seven.exe` после сборки лежит копия `assets/` (CMake копирует автоматически).

## 2. Имена кадров

- Формат: **`0001.png`**, **`0002.png`**, … (4 цифры).
- Расширение: только **PNG**.
- Кадры сортируются **по имени** — нумерация должна быть непрерывной.
- Сколько положите файлов — столько и проиграет движок (лимита «300» в коде нет).

Пример длинной анимации ухода:

```
assets/sprites/leaving/sink/
  0001.png
  0002.png
  …
  0300.png
```

## 3. Размер и фон

| Параметр | Значение по умолчанию | Где менять |
|----------|----------------------|------------|
| Размер кадра | 200×220 px | `config.h` → `SIX_SEVEN_SPRITE_WIDTH/HEIGHT` |
| Фон для вырезания | magenta `#FF00FF` | `SIX_SEVEN_COLORKEY` |
| Авто-подгонка PNG | включена | `SIX_SEVEN_SPRITE_AUTO_RESIZE` |

Рекомендации:

1. Рисуйте персонажа **на magenta-фоне** или с **прозрачностью** (alpha).
2. Если размер PNG не совпадает с `SPRITE_WIDTH×HEIGHT`, программа **впишет** кадр и при `SAVE_RESIZED=1` может перезаписать PNG на диске.
3. Оставляйте свободное место **сверху** в окне под облачко речи (`SIX_SEVEN_BUBBLE_SPACE_H`).

## 4. Регистрация: `mods.h` + `config.h`

**Пути** к папкам — в **`mods.h`**:
```cpp
#define MOD_SPRITE_LEAVING_SINK "leaving/sink"
```

**FPS** (кадров/с) — в **`config.h`**, секция **`fps_anim/`**:
```cpp
#define FPS_ANIM_IDLE           8
#define FPS_ANIM_LEAVING_SINK   10
```

Таблица `SIX_SEVEN_SPRITE_TABLE` связывает их:
```cpp
SPRITE(MOD_SPRITE_LEAVING_SINK, FPS_ANIM_LEAVING_SINK, 0)
```

- **`fps`** — скорость: при таймере 16 ms кадр меняется примерно каждые `60/fps` тиков.
  - `fps=10` → ~10 кадров/с → **300 кадров ≈ 30 секунд**.
  - `fps=14` → быстрее.
- **`loop=0`** — one-shot: после последнего кадра действие завершается.
- **`loop=1`** — повтор (idle, ходьба).

После правки **`config.h` обязательно пересоберите**:

```bat
build-mingw.bat
```

## 5. Привязка к действию

Анимация сама по себе ничего не делает — её вызывает **действие** в том же `config.h`.

| Тип | Макрос | Когда срабатывает |
|-----|--------|-------------------|
| Покой | `SIX_SEVEN_STAY_SPRITE` | между действиями |
| ПКМ | `ACTION_CLICK(...)` | меню правой кнопкой |
| Скука | `ACTION_DEF(...)` | таймер бездействия |
| Старт | `ACTION_APPEARANCE` / `ACTION_HELLO` | запуск |
| Выход | `ACTION_BYE` / `ACTION_LEAVING` | закрытие из трея |

Пример — уход вниз с фразой из файла:

```cpp
#define SIX_SEVEN_LEAVING_ACTIONS \
    ACTION_LEAVING(leave_walk, "leaving/walk", oneshot, "", "", L"") \
    ACTION_LEAVING(leave_sink, "leaving/sink", oneshot, "", SIX_SEVEN_PHRASES_LEAVING, L"")
```

- `"leaving/sink"` — папка в `assets/sprites/`.
- `oneshot` — проиграть один раз до конца.
- `SIX_SEVEN_PHRASES_LEAVING` — случайная строка из `assets/phrases/leaving/lines.txt` (озвучка + облачко).

## 6. One-shot vs loop

| Режим | Поведение |
|-------|-----------|
| **oneshot** | Кадры 1…N, затем `ReturnStay` или следующий шаг цепочки (bye→leaving→exit). |
| **loop** | Кадры крутятся, пока действие не завершит `ActionRunner` (например, конец прогулки). |

Для **ухода** используйте **oneshot** — персонаж должен доиграть все кадры.

## 7. Длинные анимации (100+ кадров)

Программа **не ограничивает** число PNG — загружаются все `*.png` из папки.

При **выходе** (bye → leaving): exe закрывается **только после последнего кадра** leaving-анимации. Таймера обрыва нет. Повторный «Выход» в трее — мгновенное закрытие.

Если анимация обрывается раньше:

1. Убедитесь, что в папке действительно все файлы `0001`…`0300`.
2. Проверьте **`fps`** в `SPRITE(...)` — длительность ≈ `кадры / fps` секунд.
3. Пересоберите exe после изменения `mods.h` / `config.h`.
4. ~~Таймер принудительного выхода~~ — отключён; ждём конец анимации.

Формула длительности:

```
время (мс) ≈ количество_кадров × (60 / fps) × 16
```

Пример: 300 кадров, fps=10 → 300 × 6 × 16 ≈ **28.8 с**.

## 8. Направления ходьбы

Для прогулки (`def` → wander) используются 8 папок:

```
movingU   movingD   movingL   movingR
movingRU  movingLU  movingRD  movingLD
```

Достаточно положить хотя бы `movingU/0001.png` — остальные подставятся по направлению движения.

## 9. Звук и текст

В макросе действия:

```cpp
ACTION_CLICK(wave_hi, L"Помахать", "click/wave", oneshot,
             "",           /* sound.wav или "" */
             "",           /* phrase_file или "" */
             L"Привет!",   /* фраза в облачко + TTS */
             0)            /* stop_tts_on_finish */
```

- **sound** — путь к WAV относительно exe (`assets/sounds/...`).
- **phrase** — текст в облачко и озвучка.
- **phrase_file** — файл со строками (по одной на строку), выбирается случайная.

## 10. Чеклист новой анимации

1. [ ] Создать папку `assets/sprites/<тип>/<имя>/`.
2. [ ] Экспортировать PNG `0001.png` … `NNNN.png`.
3. [ ] Фон magenta `#FF00FF` или прозрачность.
4. [ ] Добавить `MOD_SPRITE_*` и `MOD_FPS_*` в **`mods.h`** (при новой папке — строка в `SIX_SEVEN_SPRITE_TABLE` в config.h).
5. [ ] При необходимости — макрос действия (`ACTION_DEF`, `ACTION_LEAVING`, …).
6. [ ] Запустить `build-mingw.bat`.
7. [ ] Проверить в игре (ПКМ, выход из трея, ожидание «скуки»).

## 11. Инструменты

Подойдут любые редакторы с экспортом PNG и нумерацией кадров:

- **Aseprite**, **Krita**, **GIMP** (анимация + export layers),
- **Blender** (render sequence),
- **Pencil2D**, **OpenToonz**.

Экспорт: PNG, sRGB, без лишнего premultiply если используете magenta colorkey.
